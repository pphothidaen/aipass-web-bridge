# Implementation Plan: VS Code WebView E2E Test Suite

**Goal:** Create an automated E2E test suite using `@vscode/test-electron` and `jsdom` to test the AiPASS Chat webview buttons (🔄, 📁, ↺) and chat functionality.

**Created:** 2026-09-07 12:15

---

## Problem

`computer_use` synthetic clicks don't reach VS Code webview because webviews run in a separate Electron process that captures mouse events at the OS level before they reach the embedded HTML.

**Solution:** Use `@vscode/test-electron` to launch a real VS Code instance with the extension, then use `jsdom` to load the webview HTML and simulate clicks directly in the DOM.

### Task 2: Create test suite entry point

**File:** `packages/vscode-extension/src/test/suite/index.ts`

```typescript
import * as path from 'path';
import * as Mocha from 'mocha';
import * as glob from 'glob';

export function run(): Promise<void> {
  const mocha = new Mocha({
    ui: 'bdd',
    color: true,
    timeout: 60000,
  });

  const testsRoot = path.resolve(__dirname, '.');

  return new Promise((resolve, reject) => {
    glob('**/*.test.js', { cwd: testsRoot }, (err, files) => {
      if (err) return reject(err);

      files.forEach(f => mocha.addFile(path.resolve(testsRoot, f)));

      try {
        mocha.run(failures => {
          if (failures > 0) reject(new Error(`${failures} tests failed`));
          else resolve();
        });
      } catch (e) {
        reject(e);
      }
    });
  });
}
```

### Task 3: Create the webview E2E test

**File:** `packages/vscode-extension/src/test/suite/webview.test.ts`

```typescript
import * as assert from 'assert';
import * as path from 'path';
import * as fs from 'fs';
import { JSDOM } from 'jsdom';

suite('AiPASS Chat Webview E2E Tests', () => {
  let dom: JSDOM;
  let document: Document;
  let window: Window & typeof globalThis;

  suiteSetup(() => {
    // Load the webview HTML
    const htmlPath = path.resolve(__dirname, '../../../media/chat.html');
    const cssPath = path.resolve(__dirname, '../../../media/chat.css');
    
    let html = fs.readFileSync(htmlPath, 'utf8');
    const css = fs.readFileSync(cssPath, 'utf8');

    // Inline the CSS so styles render in jsdom
    html = html.replace(
      '<link rel="stylesheet" href="vscode-resource:../../media/chat.css">',
      `<style>${css}</style>`
    );

    dom = new JSDOM(html, {
      runScripts: 'dangerously',
      pretendToBeVisual: true,
      url: 'vscode-resource://localhost/',
    });

    window = dom.window as any;
    document = window.document;

    // Mock acquireVsCodeApi for postMessage simulation
    const postedMessages: any[] = [];
    (window as any).acquireVsCodeApi = () => ({
      postMessage: (msg: any) => postedMessages.push(msg),
      getState: () => undefined,
      setState: () => {},
    });

    // Store postedMessages for assertions
    (window as any).__postedMessages = postedMessages;

    // Initialize the webview scripts by dispatching DOMContentLoaded
    window.document.dispatchEvent(new window.Event('DOMContentLoaded'));
  });

  suiteTeardown(() => {
    dom.window.close();
  });

  test('webview has all required UI elements', () => {
    assert.ok(document.getElementById('model-select'), 'model-select should exist');
    assert.ok(document.getElementById('target-path'), 'target-path should exist');
    assert.ok(document.getElementById('refresh-models-btn'), 'refresh-models-btn should exist');
    assert.ok(document.getElementById('browse-path-btn'), 'browse-path-btn should exist');
    assert.ok(document.getElementById('path-label-btn'), 'path-label-btn should exist');
    assert.ok(document.getElementById('reset-path-btn'), 'reset-path-btn should exist');
    assert.ok(document.getElementById('input'), 'input should exist');
    assert.ok(document.getElementById('send-btn'), 'send-btn should exist');
  });

  test('🔄 refresh-models-btn posts refreshModels message', () => {
    const btn = document.getElementById('refresh-models-btn') as HTMLButtonElement;
    btn.click();

    const messages = (window as any).__postedMessages;
    const refreshMsg = messages.find((m: any) => m.type === 'refreshModels');
    assert.ok(refreshMsg, 'clicking refresh button should post refreshModels message');
  });

  test('📁 browse-path-btn posts browseTargetPath message', () => {
    const btn = document.getElementById('browse-path-btn') as HTMLButtonElement;
    btn.click();

    const messages = (window as any).__postedMessages;
    const browseMsg = messages.find((m: any) => m.type === 'browseTargetPath');
    assert.ok(browseMsg, 'clicking browse button should post browseTargetPath message');
  });

  test('path-label-btn also posts browseTargetPath message', () => {
    const btn = document.getElementById('path-label-btn') as HTMLSpanElement;
    btn.click();

    const messages = (window as any).__postedMessages;
    const browseMsg = messages.find((m: any) => m.type === 'browseTargetPath');
    assert.ok(browseMsg, 'clicking ROOT: label should post browseTargetPath message');
  });

  test('↺ reset-path-btn posts resetTargetPath message', () => {
    const btn = document.getElementById('reset-path-btn') as HTMLButtonElement;
    btn.click();

    const messages = (window as any).__postedMessages;
    const resetMsg = messages.find((m: any) => m.type === 'resetTargetPath');
    assert.ok(resetMsg, 'clicking reset button should post resetTargetPath message');
  });

  test('send button posts sendMessage message with input text', () => {
    const input = document.getElementById('input') as HTMLTextAreaElement;
    const sendBtn = document.getElementById('send-btn') as HTMLButtonElement;

    input.value = 'สวัสดีครับ ทดสอบระบบ';
    sendBtn.click();

    const messages = (window as any).__postedMessages;
    const sendMsg = messages.find((m: any) => m.type === 'sendMessage');
    assert.ok(sendMsg, 'clicking send should post sendMessage message');
    assert.strictEqual(sendMsg.value, 'สวัสดีครับ ทดสอบระบบ', 'message value should match input');
    assert.strictEqual(sendMsg.mode, 'agent', 'default mode should be agent');
  });

  test('Enter key in textarea posts sendMessage', () => {
    const input = document.getElementById('input') as HTMLTextAreaElement;
    input.value = 'hello from enter key';

    const event = new window.KeyboardEvent('keydown', {
      key: 'Enter',
      code: 'Enter',
      keyCode: 13,
      bubbles: true,
    });
    input.dispatchEvent(event);

    const messages = (window as any).__postedMessages;
    const sendMsg = messages.find((m: any) => m.type === 'sendMessage' && m.value === 'hello from enter key');
    assert.ok(sendMsg, 'pressing Enter should post sendMessage');
  });

  test('Shift+Enter does NOT post sendMessage (allows newline)', () => {
    const initialCount = (window as any).__postedMessages.length;
    const input = document.getElementById('input') as HTMLTextAreaElement;
    input.value = 'shift enter test';

    const event = new window.KeyboardEvent('keydown', {
      key: 'Enter',
      code: 'Enter',
      keyCode: 13,
      shiftKey: true,
      bubbles: true,
    });
    input.dispatchEvent(event);

    const messages = (window as any).__postedMessages;
    const newSendMsgs = messages.slice(initialCount).filter((m: any) => m.type === 'sendMessage');
    assert.strictEqual(newSendMsgs.length, 0, 'Shift+Enter should not send message');
  });

  test('slash commands are recognized', () => {
    const input = document.getElementById('input') as HTMLTextAreaElement;
    const sendBtn = document.getElementById('send-btn') as HTMLButtonElement;

    input.value = '/test please write tests';
    sendBtn.click();

    const messages = (window as any).__postedMessages;
    const sendMsg = messages.find((m: any) => m.type === 'sendMessage' && m.value?.includes('Unit Test'));
    assert.ok(sendMsg, '/test should be expanded to unit test prompt');
  });

  test('setModels message populates model dropdown', () => {
    // Simulate receiving setModels message from extension
    const models = [
      { id: 'gemini-3.1-flash-lite', name: 'Gemini 3.1 Flash Lite', provider: 'Google', kind: 'chat' },
      { id: 'claude-sonnet-5@default', name: 'Claude Sonnet 5', provider: 'Anthropic', kind: 'chat' },
    ];

    const event = new window.MessageEvent('message', {
      data: { type: 'setModels', models },
    });
    window.dispatchEvent(event);

    const select = document.getElementById('model-select') as HTMLSelectElement;
    assert.ok(select.options.length >= 2, 'model dropdown should have options');
    assert.ok(
      Array.from(select.options).some((o: any) => o.value === 'gemini-3.1-flash-lite'),
      'should contain gemini model'
    );
  });

  test('initData sets target path input', () => {
    const customPath = '/custom/project/path';
    const event = new window.MessageEvent('message', {
      data: { type: 'initData', basePath: customPath, mode: 'agent' },
    });
    window.dispatchEvent(event);

    const input = document.getElementById('target-path') as HTMLInputElement;
    assert.strictEqual(input.value, customPath, 'target path should be set from initData');
  });
});
```

## Risks

1. **jsdom limitations:** No real rendering, CSS, or layout. Tests only verify DOM structure and event handlers.
2. **acquireVsCodeApi mock:** Must match what the real API returns. If the webview uses `getState`/`setState`, those need mocking too.
3. **chat.html path:** The HTML is generated dynamically by `_getHtmlContent()`. We need to load the template directly or use the generated output.

---

## Alternative Approaches Considered

| Approach | Pros | Cons |
|----------|------|------|
| `computer_use` clicks | Real user simulation | ❌ Doesn't work on webview |
| `@vscode/test-electron` + DOM API | Direct extension access | ⚠️ Complex setup, slow |
| **`jsdom` + HTML template** | ✅ Fast, reliable, no VS Code needed | Not 100% real but tests the JS logic |
| Playwright | Real browser automation | Overkill, needs Electron config |

We chose `jsdom` because the webview is just HTML+JS — we can test all the event handling and message passing without launching VS Code.
