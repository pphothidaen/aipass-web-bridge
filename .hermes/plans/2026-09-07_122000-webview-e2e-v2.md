# Implementation Plan: WebView E2E Test Suite (Revised v2)

**Goal:** Extract inline webview JS → separate `.js` file, then test with jsdom. This makes the event handlers testable while keeping the same HTML structure.

**Created:** 2026-09-07 12:20

---

## Approach

The webview HTML in `aipassViewProvider.ts:_getHtmlContent()` contains inline `<script>` code. We will:

1. Extract the inline JS into `media/webview.js`
2. Update `_getHtmlContent()` to load it via `<script src="...">`
3. Write a jsdom test that loads `media/webview.js` and tests all event handlers

This tests the **actual production code** — no mocks, no approximations.

---

### Task 2: Update aipassViewProvider.ts to load external JS

**File:** `packages/vscode-extension/src/ui/aipassViewProvider.ts`

In `_getHtmlContent()`, replace the inline `<script>...</script>` with:

```typescript
const scriptUri = webviewView.webview.asWebviewUri(
  vscode.Uri.joinPath(this._extensionUri, 'media', 'webview.js')
);
```

Then in the HTML template, replace the entire inline script block with:
```html
<script src="${scriptUri}"></script>
```

Also add `webview.js` to the `localResourceRoots` if not already included via `media`.

### Task 3: Add jsdom test infrastructure

**File:** `packages/vscode-extension/src/test/suite/webview.test.ts` (NEW)

```typescript
import * as assert from 'assert';
import * as path from 'path';
import * as fs from 'fs';
import { JSDOM, VirtualConsole } from 'jsdom';

suite('AiPASS Chat Webview', () => {
  let dom: JSDOM;
  let window: Window & typeof globalThis;
  let document: Document;
  let postedMessages: any[];

  suiteSetup(() => {
    // Load the webview JS file
    const jsPath = path.resolve(__dirname, '../../../media/webview.js');
    const jsCode = fs.readFileSync(jsPath, 'utf8');

    // Capture console output for debugging
    const virtualConsole = new VirtualConsole();
    virtualConsole.on('error', () => {});
    virtualConsole.on('log', () => {});

    postedMessages = [];

    // Create a minimal DOM that the webview JS expects
    dom = new JSDOM(
      `<!DOCTYPE html>
      <body>
        <select id="model-select"></select>
        <span id="model-name"></span>
        <input id="target-path" />
        <button id="browse-path-btn">📁</button>
        <span id="path-label-btn">Root:</span>
        <button id="reset-path-btn">↺</button>
        <button id="refresh-models-btn">🔄</button>
        <div id="chat-history"></div>
        <div id="status"></div>
        <textarea id="input"></textarea>
        <button id="send-btn">Send</button>
        <select id="mode-select">
          <option value="agent">Agent</option>
          <option value="chat">Chat</option>
        </select>
      </body>`,
      {
        runScripts: 'outside-only',
        pretendToBeVisual: true,
        virtualConsole,
      }
    );

    window = dom.window as any;
    document = window.document;

    // Mock acquireVsCodeApi
    (window as any).acquireVsCodeApi = () => ({
      postMessage: (msg: any) => postedMessages.push(msg),
      getState: () => undefined,
      setState: () => undefined,
    });

    // Execute the webview JS in the jsdom context
    const script = new window.Function(jsCode);
    script.call(window);
  });

  suiteTeardown(() => {
    dom.window.close();
  });

  test('clicking refresh-models-btn posts refreshModels', () => {
    const btn = document.getElementById('refresh-models-btn')!;
    btn.click();
    assert.ok(postedMessages.some(m => m.type === 'refreshModels'));
  });

  test('clicking browse-path-btn posts browseTargetPath', () => {
    const btn = document.getElementById('browse-path-btn')!;
    btn.click();
    assert.ok(postedMessages.some(m => m.type === 'browseTargetPath'));
  });

  test('clicking reset-path-btn posts resetTargetPath', () => {
    const btn = document.getElementById('reset-path-btn')!;
    btn.click();
    assert.ok(postedMessages.some(m => m.type === 'resetTargetPath'));
  });

  test('pressing Enter in input sends message', () => {
    const input = document.getElementById('input') as HTMLTextAreaElement;
    input.value = 'test message';
    input.dispatchEvent(new window.KeyboardEvent('keydown', { key: 'Enter', bubbles: true }));
    assert.ok(postedMessages.some(m => m.type === 'sendMessage' && m.value === 'test message'));
  });
});
```
