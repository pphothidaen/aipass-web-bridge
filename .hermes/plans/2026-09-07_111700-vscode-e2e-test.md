## Risks

1. **Coordinate sensitivity:** VS Code window may not be at exact position. Always re-capture before clicking.
2. **Native dialog automation:** macOS Open Dialog may require Accessibility permissions. If `computer_use` can't click it, report as "cannot automate native dialog" and test backend code path instead.
3. **Model loading delay:** Bridge may take 30-60s to load models on first open. Be patient.
4. **Delivery mode:** Always use `delivery_mode: "foreground"` for keyboard/mouse events in VS Code.
